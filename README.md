# 刻印 Kokuin

日本語で韓国語の単語を覚えるための PWA です。自分用に作って、iPhone と iPad の Safari でホーム画面に追加して使っています。

FSRS（分散反復）で毎日復習する単語を決めて、韓→日（意味を思い出す）と日→韓（韓国語で書く）の両方向で練習します。単語の覚え方について調べたことは [EVIDENCE.md](EVIDENCE.md) にまとめました。

## 機能

- 単語を入れると意味・例文・カナ読みを自動で取得（内蔵単語帳 → Google 辞書 → MyMemory の順）。カナ読みはハングルから端末内で作るのでオフラインでも出ます
- 1単語でカード2枚: 韓→日（意味を思い出す）と日→韓（手書きかタイピングで答える）
- FSRS-5 で出題。覚えている単語ほど間隔が伸びます
- 正解を見たあとに手書きでなぞる「仕上げ」（回数は設定で変更）
- 復習モード: 今日・7日・全体の単語をまとめてテスト（FSRS の予定には影響しない）
- 発音・リスニング練習: シャドーイング、ディクテーション、スピーキング
- 内蔵単語帳 5つ・1,108語（TOPIK I、TOPIK II 中級・上級、日常会話、旅行）
- ダーク/ライトテーマ、よく間違える単語（リーチ）の検出、統計、連続学習日数
- 端末間の同期（任意）: 同期パスワードで暗号化して Cloudflare KV に保存
- オフライン対応、JSON でバックアップと復元

## 使い方

1. 「追加」タブで単語を入れて「自動取得」、内容を確認して保存（単語帳タブからまとめて追加もできます）
2. ホームの「復習開始」で今日の分を復習
3. 1日の新出単語数（既定 15）や目標保持率（既定 90%）は設定から変更

## デプロイ

Service Worker を使うので HTTPS が必要です。

**Cloudflare Pages**（同期も使う場合）

1. Workers & Pages → Create → Pages → Upload assets で、このフォルダの中身をアップロード
2. 同期を使うなら KV namespace を作り、プロジェクトの Settings → Bindings に `SYNC_KV` という名前で追加して再デプロイ
3. 各端末の 設定 → 端末間の同期 で同じパスワードを入れる

**GitHub Pages**（同期なし）

Settings → Pages で `main` ブランチのルートを公開するだけです。

iOS では Safari で開いて「ホーム画面に追加」してください。他のブラウザから追加するとオフライン保存がうまく動きません。

ローカルで試すとき:

```bash
python3 -m http.server 8765
```

## メモ

- ビルドなしの静的 PWA（`index.html` + `js/` の ES モジュール + `sw.js`）
- データは端末の IndexedDB にだけ保存。Safari のサイトデータを消すと消えるので、たまに 設定 → エクスポート でバックアップ
- 同期データは端末側で AES-GCM で暗号化してから送るので、サーバー側では中身が読めない
- カナ読み（[js/hangul.js](js/hangul.js)）は連音や ㄱ/ㄷ/ㅂ/ㅈ の有声化など主な規則だけの近似
- 単語帳を作り直すときは `data/decks/_gen/` を編集して `node tools/assemble-decks.mjs`
- 更新を出すときは `sw.js` の `CACHE` を上げる
